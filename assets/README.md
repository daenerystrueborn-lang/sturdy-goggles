# Assets

Drop real images/assets here and reference them by relative URL, e.g.:

```js
state.player.avatar = "assets/player.png";
state.banner = "assets/banner.jpg";
state.shop = [
  { name: "...", desc: "...", price: 450, image: "assets/item.png" },
];
```

This directory is intentionally empty — no placeholder/demo files are shipped.
